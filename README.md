##  Proyecto: Menú Dinámico utilizando Estructura de Datos (JSON)

Aplicación web desarrollada como práctica de laboratorio, cuyo objetivo es generar de forma dinámica las opciones de un menú de navegación (incluyendo submenús desplegables) a partir de datos externos estructurados en **JSON**, utilizando JavaScript asíncrono (`Fetch API`).

---

##  Investigación de Conceptos (Intercambio de Datos entre Aplicaciones)

Como parte de los requisitos de la práctica, se detallan los conceptos fundamentales utilizados en la comunicación de sistemas modernos:

* **API (Application Programming Interface):** Conjunto de reglas, protocolos y subrutinas que permite que diferentes aplicaciones de software se comuniquen e interactúen entre sí de manera estandarizada.
* **REST (Representational State Transfer):** Estilo de arquitectura ligera basada en el protocolo HTTP. Utiliza métodos estándar (GET, POST, PUT, DELETE) para la transferencia de recursos, siendo el formato JSON su aliado más común.
* **SOAP (Simple Object Access Protocol):** Protocolo de mensajería estricto y altamente estructurado basado en XML. Se caracteriza por su alto nivel de seguridad y cumplimiento normativo, frecuentemente utilizado en entornos empresariales y bancarios.
* **JSON (JavaScript Object Notation):** Formato ligero de intercambio de datos basado en texto plano con una estructura de pares clave-valor. Es fácil de leer para los humanos y muy rápido de procesar para los navegadores y lenguajes modernos.
* **XML (Extensible Markup Language):** Lenguaje de marcado jerárquico que utiliza etiquetas personalizadas para definir la estructura de los datos. Aunque es más pesado que JSON, destaca por su robustez y validación mediante esquemas (XSD).
* **GraphQL:** Lenguaje de consulta para APIs desarrollado por Facebook. Permite a los clientes solicitar exactamente los datos específicos que necesitan en una sola petición, evitando la sobrecarga o escasez de información.
